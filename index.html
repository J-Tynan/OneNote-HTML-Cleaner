    How to use OneNote HTML Cleaner

    This tool converts exported OneNote MHTML files locally in your browser. Expand the sections below for the parts you need.

    Start a conversion

    Add an MHTML file (.mht/.mhtml) using the Browse button or by dragging it into the dropzone. The app converts the file locally in your browser and provides a download link when finished.

    Handwriting exported from OneNote via MHTML is preserved as raster imagery. Appearance can vary by OneNote theme at export time, and vector ink editing is not available in this path.

    HTML output and ZIP export

    Converted pages are validated to avoid required CDN or app-runtime dependencies. If you enable Externalize CSS, use ZIP output so HTML and CSS sidecar assets stay together.

    Shared mode writes one stylesheet for the ZIP. Per-page mode writes one stylesheet per exported HTML page.

    Export formats

    Experimental export controls are available in Advanced options. HTML remains the default stable path, and Markdown is available with selectable flavor.

    Planned Markdown export follows a structure-first approach, with Obsidian-compatible output as the default flavor.

    Converted-page options

    Converted-page theme toggle is available for HTML exports. When enabled, exported pages include a Light or Dark symbol toggle, and an optional OLED-black dark variant for page and main content surfaces.

    If toolbar injection is enabled for converted pages, the toolbar starts hidden by default. Use the small Toolbar button beside the page theme toggle to reveal it.
