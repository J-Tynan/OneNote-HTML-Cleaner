    How to use OneNote HTML Cleaner

    Add an MHTML file (.mht/.mhtml) using the Browse button or by dragging it into the dropzone. The app converts the file locally in your browser and provides a download link when finished.

    Converted pages are validated to avoid required CDN/app-runtime dependencies. If you enable Externalize CSS, use ZIP output so HTML and CSS sidecar assets stay together.

    Handwriting exported from OneNote via MHTML is preserved as raster imagery. Appearance can vary by OneNote theme at export time, and vector ink editing is not available in this path.

    Planned Markdown export follows a structure-first approach (semantic fidelity over visual parity), with Obsidian-compatible output as the default flavor.
