  1. Teamwork on GitHub

Pull requests are the foundation of teamwork on GitHub. They give you the ability to work together and discuss changes specific to a pull request by commenting, requesting changes or approving.
  1. Starting from Main

When creating a new pull request, in the base: dropdown, make sure "main" is selected. Select the compare: dropdown, and click on the other branch.
  1. What is a pull request review?

Pull request reviews ensure quality and maintain momentum of changes to your project.
Reviewing a pull request is an opportunity to examine another contributor's changes and give them feedback.
On GitHub, you can ask someone to review a pull request by assigning them as a reviewer or assignee. If you are not ready for a review, consider creating a draft pull request instead.
  1. When reviewing a pull request follow these steps:
  1. Review the title and body of the pull request, and possible any associated issue, to understand the intended change.
  2. Review the diff, the comparison of the proposed code, in the context of the whole project.
  3. For most things, try out the proposed change. Check if the actual change matches the intention. Find the repository's contributing guide to find out how to review the changes.
  1. Tips for review comments

Identify potential issues, risks and limitations.

Suggest changes and improvements.

Share awareness of upcoming changes that the pull request doesn't account for.

Ask questions to verify shared understanding.

Highlight what the author did well and should keep doing.

Prioritise the most important feedback.

Be concise and provide meaningful detail.

Treat the pull request author with kindness and empathy.
  1. When a pull request is not ready

When an approval or request for changes is not yet needed, consider using comments.

An approval lets the author know you believe the pull request is safe to merge.

Requesting changes lets the author know you believe the pull request is not ready to merge.
  1. Suggest changes

On GitHub pull requests, the 'suggest changes' feature enables you to recommend a change to a pull request that the author can commit with the push of a button.
On "Files changed" tab, mouse-hover next to the line numbers and click the blue icon to open the editor, click on "Add a suggestion" and click the button 'Add a single comment'.
  1. Follow-up

As you continue working on GitHub, remember that high quality reviews improve your projects. If you are new to a repository, inquire about what review practices.
