| Cues Notes Course outline In this course, using Markdown I will: Add headers, add an image, add a code example, make a task list and merge a pull request. What is Markdown? File extensions? Markdown files end with an extension of either.md or.markdown however I would aim to always use the.md extension. What is a header? A header is a larger bit of text at the beginning of a section. There are six sizes. # This is an \`<h1>\` header, which is the largest. ## This is an \`<h2>\` header. ###### This is an \`<h6>\` header, which is the smallest. Adding images Adding code blocks var myVar = "Hello, world!"; \`\`\` Adding a task list A Markdown task list creates checkboxes to check/tick off. You can only check/tick these boxes by editing the file. Example: - \[x\] List syntax is required - \[x\] This item is complete - \[ \] This item is not complete Merge the pull request(s) Click on 'Merge pull requests' and delete the old branch. Recap of tasks I have learned about Markdown, headings, images, code examples, and task lists. Also I have created a merged a GitHub Markdown file. Follow-up You can enable GitHub Pages and see your Markdown file as a website! Publish README as website Under your repository name at the upper right, click "Settings". Then on the lower left, click 'Pages' in the 'Code and automation' section. In the GitHub Pages section, ensure "Deploy from a branch" is selected from the Source drop-down menu, and then select main from the Branch drop-down menu as your GitHub Pages publishing source. Click the 'Save' button. Wait about 30 seconds then refresh the page. When you see "Your site is published at..." you can click on the link to see your published site. |  |  |  |  |
